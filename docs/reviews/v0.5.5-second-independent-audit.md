## What `fwd` is (one paragraph)

`fwd` is the Flare Wallet Daemon: a single-host, single-operator, Docker-Compose policy-gated EVM signing daemon for African Proofs. Its entire purpose is to delete every `.env PRIVATE_KEY=` line across AP automation and replace each with one HTTP call to a service that decodes intent, enforces default-deny policy, custodies keys envelope-encrypted by HashiCorp Vault Transit (`aes256-gcm96`, `exportable=false` — note `decisions.md` D1: Vault does NOT sign; the original "keys never leave the signer" design died at v0.1.2 and Vault is now an envelope-encrypt/decrypt oracle), and keeps a hash-chained audit log. Phase 7 GA is met on Coston2; Phase 8 (`ftso-fee-claimer` cutover — the first real `.env` deletion) is the next feature ship and has not started.
