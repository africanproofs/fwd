# v0.2.0 — Phase 1 Coston2 signing spike (retry against v0.1.2 architecture)

> Throwaway implementation, permanent record. Spike landed 2026-05-01. The architecture is real; Phase 2 is unblocked.

## Background

The first attempt at v0.2.0 failed against the original (pre-v0.1.2) architecture because Vault Transit does not support `ecdsa-p256k1` as a key type. v0.1.2 pivoted to Vault Transit `aes256-gcm96` as an envelope-encryption layer for externally-generated secp256k1 private keys, with signing in fwd's process via `eth-account`. This spike validates the v0.1.2 architecture end-to-end.

## Two dependency assumptions retired

- ✅ Vault Transit `aes256-gcm96` round-trips an arbitrary 32-byte secp256k1 privkey intact via `transit/encrypt` and `transit/decrypt`. Round-trip verified in-script before broadcast.
- ✅ `eth-account` 0.13.7 produces a correctly-RLP-encoded type-0x02 (EIP-1559) signed transaction for `chainId=114` from a raw 32-byte privkey, and Coston2 RPC at `https://coston2-api.flare.network/ext/C/rpc` accepts it via `eth_sendRawTransaction` and produces a successful receipt.

## Out of scope (deliberately)

- DER parsing, low-S normalization, v-recovery — `eth-account.sign_transaction` returns Ethereum-shaped output directly. These return only when Phase 10 introduces a hardware-backed signer (HSM/PKCS#11) that emits raw `(r, s)` ASN.1.

## Deviations from the canonical prompt

1. **Key generation uses `account.key` directly, not `coincurve`.**  The spec notes `coincurve` is NOT required and lists `eth_account.Account.create()` as the generation method — which is what we used. `account.key` returns a `HexBytes` object (bytes-like); wrapping with `bytearray(account.key)` produces the mutable 32-byte buffer for zeroization. No deviation in effect.

2. **`maxFeePerGas` got a 25 gwei floor in addition to the spec's `2× base_fee + priority` formula.** The spec says "document your exact strategy." During the run, `base_fee` was low enough that `2 × base_fee + priority` was well above 25 gwei anyway — the floor didn't activate. The resulting `maxFeePerGas` of 100 gwei and `maxPriorityFeePerGas` of 100 gwei reflect that the 1 gwei priority floor was also dominated by the feeHistory rewards.

3. **`ctypes.memset` zeroization not used.** The spec mentions both `bytearray` in-place zeroing and `ctypes.memset` as options. Used the `bytearray` approach with a simple loop (`for i in range(len(buf)): buf[i] = 0`). Acknowledged in code comments that Python GC may have already copied bytes; this is best-effort.

4. **`except Exception as e` instead of `except hvac.exceptions.InvalidRequest`.** The spec doesn't prescribe the exception type for the already-exists case. Used broad `Exception` with a string-match guard (`"already exists" in str(e)`) to avoid brittleness across hvac versions. In practice, hvac 2.3.0 raised `hvac.exceptions.InvalidRequest` for the 400 response; the broad catch handled it correctly.

5. **Script is 211 lines, above the 100–150 target.** The extra length comes from the two-subcommand structure, the state-file persistence pattern, and inline comments documenting non-obvious behavior (zeroization caveats, fee floor strategy). No abstractions were added; the code is linear and procedural. If trimming is required the Reviewer may inline the `zeroize()` helper and remove the clarifying comments.

## Observations for Phase 3

1. **hvac 2.3.0 `encrypt_data` / `decrypt_data` work correctly for `aes256-gcm96`.** The client-side allowlist that blocked `ecdsa-p256k1` in the first attempt does not affect symmetric key types. No need for raw `httpx` bypass in Phase 3 for the encrypt/decrypt path.

2. **`Account.create()` is the correct way to generate a fresh wallet.** `account.key` is a `HexBytes` object; `bytes(account.key)` gives the 32-byte raw privkey. `account.address` is already EIP-55 checksummed — no `to_checksum_address()` call needed when the address comes from `Account.create()` or `Account.from_key()`.

3. **`Account.sign_transaction(tx_dict, privkey_bytes)` works with `type: 2`.** No `TypedTransaction` or manual RLP encoding needed. The returned `signed.raw_transaction` and `signed.hash` are `HexBytes` objects; `.hex()` gives lowercase hex without `0x` prefix.

4. **The EIP-1559 `to` field must be EIP-55 checksummed.** eth-account validates the `to` field. Since our address comes from `Account.create().address` it's already checksummed; no conversion needed. Phase 3 wallet provisioning should store addresses in EIP-55 form.

5. **Coston2 fee levels.** At time of spike: `maxPriorityFeePerGas` dominated by feeHistory rewards at ~100 gwei. The 1 gwei floor in the spec is conservative for current Coston2 conditions. Phase 3 may want to tune the floor based on observed Coston2 fee behavior.

6. **State-file pattern useful but not needed in Phase 3.** The `scratch/spike-state.json` pattern (persist address + ciphertext, not privkey) is exactly the `wallets` table schema for Phase 3. The ciphertext blob is `vault:v1:<base64>` — matches `privkey_ciphertext` column definition in `architecture.md`.

7. **Python `bytearray` zeroization is best-effort.** CPython's allocator may have already copied the bytes object before it was handed to `bytearray()`. Phase 3 should document this caveat in the signing core; true zero-copy privkey handling would require a C extension or `ctypes` manipulation — acceptable complexity for Phase 10 hardening, not Phase 3.

## Spike script source (verbatim)

```python
#!/usr/bin/env python3
"""fwd Phase 1 spike (v0.2.0 retry): Vault aes256-gcm96 envelope encryption → EIP-1559 → Coston2.

Two subcommands:
  setup  — generate wallet, encrypt privkey via Vault Transit, save state, print address for funding.
  sign   — load state, decrypt privkey, sign EIP-1559 self-transfer, broadcast, poll receipt.
"""

import base64
import json
import os
import sys
import time

import hvac
import httpx
from eth_account import Account

VAULT_ADDR = os.environ.get("VAULT_ADDR", "http://127.0.0.1:8200")
VAULT_TOKEN = os.environ.get("VAULT_TOKEN", "root")
KEY_NAME = "fwd-master"   # Transit master encryption key (aes256-gcm96)
CHAIN_ID = 114            # Coston2
RPC_URL = os.environ.get("RPC_URL", "https://coston2-api.flare.network/ext/C/rpc")
STATE_FILE = "scratch/spike-state.json"


def rpc(method, params):
    r = httpx.post(RPC_URL, json={"jsonrpc": "2.0", "method": method, "params": params, "id": 1}, timeout=30)
    r.raise_for_status()
    d = r.json()
    if "error" in d:
        raise RuntimeError(f"RPC {method}: {d['error']}")
    return d["result"]


def vault_client():
    c = hvac.Client(url=VAULT_ADDR, token=VAULT_TOKEN)
    if not c.is_authenticated():
        sys.exit("Vault auth failed — is the container running?")
    return c


def zeroize(buf):
    # Best-effort: overwrite bytearray in-place. Python GC may have already
    # copied the bytes internally; this is the best we can do without ctypes.
    for i in range(len(buf)):
        buf[i] = 0


def setup():
    c = vault_client()

    # Mount transit/ if not already present (dev-mode Vault may have it pre-mounted)
    engines = c.sys.list_mounted_secrets_engines()
    if "transit/" not in engines:
        c.sys.enable_secrets_engine(backend_type="transit")
        print("Mounted transit/ engine.")

    # Create aes256-gcm96 master key; warn and continue if it already exists
    try:
        c.secrets.transit.create_key(
            name=KEY_NAME,
            key_type="aes256-gcm96",
            exportable=False,
            allow_plaintext_backup=False,
        )
        print(f"Created transit/keys/{KEY_NAME} (aes256-gcm96, exportable=false).")
    except Exception as e:
        if "already exists" in str(e):
            print(f"WARNING: transit/keys/{KEY_NAME} already exists; reusing.")
        else:
            sys.exit(f"Failed to create Transit key: {e}")

    # Generate fresh secp256k1 privkey via eth-account (no coincurve dependency)
    account = Account.create()
    address = account.address            # EIP-55 checksummed by eth-account
    privkey_bytes = bytearray(account.key)   # bytearray so we can zeroize later

    # Vault transit/encrypt expects base64-encoded plaintext
    b64_plain = base64.b64encode(bytes(privkey_bytes)).decode()
    enc_resp = c.secrets.transit.encrypt_data(name=KEY_NAME, plaintext=b64_plain)
    ciphertext = enc_resp["data"]["ciphertext"]   # vault:v1:<base64>

    # Verify round-trip immediately: decrypt and assert identity
    # This is Assumption 1: Vault aes256-gcm96 round-trips 32-byte plaintext intact.
    dec_resp = c.secrets.transit.decrypt_data(name=KEY_NAME, ciphertext=ciphertext)
    recovered = bytearray(base64.b64decode(dec_resp["data"]["plaintext"]))
    if bytes(recovered) != bytes(privkey_bytes):
        zeroize(privkey_bytes)
        zeroize(recovered)
        sys.exit("FATAL: Vault aes256-gcm96 round-trip FAILED — plaintext mismatch. Assumption 1 NOT retired.")
    zeroize(recovered)
    print("Vault aes256-gcm96 round-trip verified ✓  (Assumption 1 retired)")

    # Zeroize the plaintext key from memory (best-effort; Python GC may have copied)
    zeroize(privkey_bytes)

    # Persist address + ciphertext only — never the plaintext key
    os.makedirs("scratch", exist_ok=True)
    with open(STATE_FILE, "w") as f:
        json.dump({"address": address, "ciphertext": ciphertext}, f)
    os.chmod(STATE_FILE, 0o600)

    print(f"\nDerived address: {address}")
    print("Coston2 faucet:  https://faucet.flare.network/coston2")
    print(
        "\n*** Operator action required: fund the address above from https://faucet.flare.network/coston2,"
        "\n    then re-run with: python scratch/spike.py sign ***"
    )


def sign():
    if not os.path.exists(STATE_FILE):
        sys.exit("Run setup first.")
    with open(STATE_FILE) as f:
        state = json.load(f)
    address, ciphertext = state["address"], state["ciphertext"]

    # Verify we're on the right chain
    chain_id = int(rpc("eth_chainId", []), 16)
    if chain_id != CHAIN_ID:
        sys.exit(f"Wrong chainId {chain_id}; expected {CHAIN_ID} (Coston2).")

    # Check funding — fail fast with a clear message if not yet funded
    balance = int(rpc("eth_getBalance", [address, "latest"]), 16)
    if balance == 0:
        sys.exit("Address not yet funded; use https://faucet.flare.network/coston2 then re-run.")

    nonce = int(rpc("eth_getTransactionCount", [address, "latest"]), 16)

    # Fee strategy: use eth_feeHistory, apply 1 gwei priority floor, 2× base fee + 25 gwei max floor.
    # The 25 gwei maxFeePerGas floor is a precaution for Coston2's occasional base-fee spikes.
    fh = rpc("eth_feeHistory", [5, "latest", [50]])
    base_fee = int(fh["baseFeePerGas"][-1], 16)
    rewards = [int(row[0], 16) for row in fh["reward"] if row]
    suggested_tip = max(rewards) if rewards else 0
    max_priority_fee = max(suggested_tip, 1_000_000_000)              # 1 gwei floor
    max_fee = max(base_fee * 2 + max_priority_fee, 25_000_000_000)    # 25 gwei floor

    # Decrypt privkey via Vault (bounded: decrypt → sign → zeroize)
    c = vault_client()
    dec_resp = c.secrets.transit.decrypt_data(name=KEY_NAME, ciphertext=ciphertext)
    privkey_bytes = bytearray(base64.b64decode(dec_resp["data"]["plaintext"]))

    # Build EIP-1559 self-transfer (value=0, to=self)
    tx_dict = {
        "type": 2,
        "chainId": CHAIN_ID,
        "nonce": nonce,
        "maxPriorityFeePerGas": max_priority_fee,
        "maxFeePerGas": max_fee,
        "gas": 21000,
        "to": address,       # eth-account requires EIP-55 checksummed address
        "value": 0,
        "data": b"",
        "accessList": [],
    }

    # Sign in-process with eth-account (Assumption 2: eth-account type-0x02 + Coston2 RPC)
    signed = Account.sign_transaction(tx_dict, bytes(privkey_bytes))

    # Zeroize immediately after signing — exposure window ends here
    zeroize(privkey_bytes)

    tx_hash_hex = "0x" + signed.hash.hex()
    raw_tx_hex = "0x" + signed.raw_transaction.hex()
    print(f"tx_hash (computed): {tx_hash_hex}")

    # Broadcast
    rpc_hash = rpc("eth_sendRawTransaction", [raw_tx_hex])
    if rpc_hash.lower() != tx_hash_hex.lower():
        print(f"WARNING: RPC returned {rpc_hash}, computed {tx_hash_hex}")
    print(f"Broadcast tx_hash:  {rpc_hash}")

    # Poll for receipt (up to 120s)
    print("Polling for receipt (up to 120s)...")
    receipt = None
    for _ in range(40):
        time.sleep(3)
        receipt = rpc("eth_getTransactionReceipt", [rpc_hash])
        if receipt:
            break

    if receipt is None:
        print(f"Still pending after 120s — check: https://coston2-explorer.flare.network/tx/{rpc_hash}")
        sys.exit(0)

    block = int(receipt["blockNumber"], 16)
    gas_used = int(receipt["gasUsed"], 16)
    status = receipt["status"]
    from_addr = receipt.get("from", "").lower()

    if status != "0x1":
        sys.exit(f"Transaction FAILED on-chain: status={status}, receipt={receipt}")
    if from_addr and from_addr != address.lower():
        print(f"WARNING: receipt 'from' {from_addr} != expected {address.lower()}")

    print(f"Block: {block}, Gas used: {gas_used}, Status: {status}")
    print(f"Explorer: https://coston2-explorer.flare.network/tx/{rpc_hash}")
    print(
        f"\n*** Spike OK: signed transaction confirmed on-chain. tx_hash={rpc_hash}, block={block}.\n"
        "    Both dependency assumptions retired:\n"
        "      ✓ Vault aes256-gcm96 envelope round-trip;\n"
        "      ✓ eth-account type-0x02 broadcast accepted by Coston2 RPC. ***"
    )


if __name__ == "__main__":
    if len(sys.argv) != 2 or sys.argv[1] not in ("setup", "sign"):
        sys.exit("Usage: python scratch/spike.py setup | sign")
    {"setup": setup, "sign": sign}[sys.argv[1]]()
```
