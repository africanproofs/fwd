# v1.1.0a79 — observability + fail-closed rate default

**Type:** daemon observability + a default-deny correction. No API shape change beyond `/healthz`.
**Date:** 2026-06-06.

## Why

Two gaps: (1) the daemon emitted no signal on auth failures or policy denials — a misconfigured caller or a probing attacker was invisible in the logs; (2) `/healthz` reported only a stat-probe `master` field, so an orchestrator could not tell whether the sealed master was actually *loadable*; (3) `RateRepo` treated an unconfigured rate as **allow** — a silent hole in the default-deny posture (Core invariant #2).

## What changed

- **`api/caller_auth.py`** — `require_caller` now logs `auth.failed` on a missing/invalid bearer token, recording only the first 8 chars of the presented key (already masked). No token material is logged.
- **`api/health.py` + new `app/health.py`** — `/healthz` gains a `sealed_master` liveness field. `sealed_master_liveness()` (app layer, to keep `api → app` layering) instantiates `SealedMaster()` on every request — verifying path, mode 0600, ownership, size, readability — then zeroizes the in-memory key immediately. On failure `/healthz` returns **503 `{status: degraded}`**. Not cached: it is a liveness probe, not a hot-path readiness cache.
- **`app/sign_transaction.py`** — logs `sign.denied` (caller, wallet, step, reason) on `PolicyDenied`, before the forensic audit row.
- **`infra/rate_repo.py`** — **fail-closed change:** `check_and_increment` returns `False` (deny) when `rate is None`, where it previously returned `True` (allow). An operator must now set a rate in policy to permit signing. Added a comment documenting per-caller-per-wallet rate isolation (the bucket key includes `caller`, so one caller cannot exhaust another's budget for the same wallet).

## Verification

Unit suite green. `/healthz` returns the new `sealed_master` field with the master present; returns 503 `degraded` when the master file is absent/wrong-mode (health-endpoint tests). Rate-deny-on-`None` covered by the rate_repo tests (flipped expectation).
