# v1.1.0a99 — fwd emits the one-shot handoff bundle (ADR-0001 §4; phased, emit-first)

**Type:** constitutional-amendment + feature. Ratified under flaresystems **ADR-0003** (interface-cohesion; clif = reference; `fwd-client` unchanged). `docs/decisions.md` **D26**.
**No signing-path change** — `policy_engine`, sealed master, nonce manager, the sign endpoints are UNTOUCHED; emission is a local file write (zero-egress intact). `env_write` is byte-unchanged (additive).
**Date:** 2026-06-10.

## Headline

fwd now composes the pinned v1 **handoff bundle** (the bearer caller tokens it mints) to a local mode-0600 file, for clif to `import-credentials` — closing the ADR-0001 "one-shot local bundle, no consumer key" handoff. **Phased (emit-first):** the bundle is emitted **alongside** the existing `--clif-env-dir` `.env` write; retiring that env-write is **Unit 4b** (gated, after the Songbird canary). **Core #7 is the load-bearing review point: the bundle holds BEARER tokens, never a signing key** — guarded and tested.

## What changed

- **`src/fwd/app/bundle_emit.py` (new)** — `compose_bundle(...)` builds the §4 shape (`issued_at`/`expires_at` via fwd's local clock; **Core #7 `*PRIVATE_KEY*` refuse-guard** on env name AND token value; rejects an unclean token clif would reject) + `write_bundle(...)` (0600 atomic via `mkstemp`+`fchmod`+`os.replace`). No infra import; no outbound connection.
- **`src/fwd/cli/bundle.py` (new, mounted in `cli/main.py`)** — `clifwd bundle compose` (stdin TAB-tuples → stdout bundle JSON), the in-container composer for onboard's host-side write. Never logs a token value.
- **`src/fwd/cli/capability.py`** — `capability grant --emit-bundle <path> [--replace] [--ttl-seconds]`: minted token VALUES go to a 0600 bundle instead of stdout; **fail-closed** (a partial mint writes no bundle); `--replace` threads rotation.
- **`install/onboard`** — additive `bundle_emit()` after `env_write` (onboard:653): composes via `clifwd bundle compose`, writes `${CLIF_ENV_DIR}/.fwd-bundle.<net>.json` host-side 0600 (mirrors `env_write` incl. the `grep -qi PRIVATE_KEY` guard + `chown 1000`); a bundle-emit failure is a non-fatal warn (the env-write fallback stays). `env_write`/`--clif-env-dir` byte-unchanged.

## The two custody caveats (Phase-0 against live code; accepted)

1. **`capability grant --emit-bundle` writes a CONTAINER-relative path** — that CLI runs in-container (it mints via `fwd:8080`, which has no host port) and `${CLIF_ENV_DIR}` is not mounted into fwd (de-intermingle, D23). The **canary uses the `onboard` HOST-side path**; `--emit-bundle` is the rotation path (host delivery via a bind-mount / `docker cp`; documented in `--help`).
2. **The `onboard` bundle WRITE is host-side shell**, not Python `write_bundle` — same root cause (`/opt/clif` is host-only). The in-container Python composes + Core-#7-guards; `onboard` writes 0600 mirroring `env_write`. **Identical token exposure to the existing `caller_ensure`** capture pipe.
