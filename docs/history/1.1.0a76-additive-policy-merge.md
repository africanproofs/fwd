# v1.1.0a76 — additive onboarding: adding a network never removes an existing one

**Type:** policy-generator feature (`app/policy_init.py` + `cli/policy.py` + `install/onboard`). Custody-critical (the policy is the signing allow-list).
**Date:** 2026-06-04.

## Why (operator directive)

Onboarding a second network silently destroyed the first. `clifwd policy init --networks X` generates a policy for *exactly* X, and the onboard does `cat new > policy.yaml` — a full **replace**. So `--networks flare` emitted a flare-only policy that overwrote Songbird's, orphaning Songbird's wallets (no policy → fwd denies). The only workaround was re-listing every network every time (`--networks songbird,flare`) — fragile. Operator invariant: **adding a network must never remove an existing one.**

## What changed

- **`app/policy_init.py`** — `generate_policy(...)` gains `merge_into: str | None`. When set (the current policy YAML), the generated network rules are **unioned into it** via `_merge_policies`. Every emitted key is network-suffixed (`claim-<net>`, `claimer-<net>`, `perm/claim-<net>`, `fsp/<net>`, `wc/fsp-<net>`, the `fsp_self_submit` entry), so distinct networks never collide: merging **adds** the requested network and leaves every other network's rules byte-identical. Re-running a network overwrites only its own (deterministically identical) keys — idempotent. Each section is unioned per-key; `fsp_self_submit` is an order-preserving list union. A non-mapping / invalid-YAML merge target is rejected (`PolicyInitError`).
- **`cli/policy.py`** — `clifwd policy init --merge` reads the live policy (`FWD_POLICY_PATH`) and passes it as `merge_into`. Plain `policy init` stays a fresh generate.
- **`install/onboard`** — the policy step passes `--merge`, so `fwd onboard rewards --networks flare …` **adds** Flare and leaves Songbird intact. The first onboard merges into the inert default (`version: 1`) = a clean fresh policy; later onboards accumulate. (Pairs with a75, which preserves each network's own `.env.<net>` identity/recipient.)
