# v1.1.0a106 — FSP rate is a cadence-safe ceiling (was below the per-round duty cycle)

**Ship type:** fix (ship-blocker). Implemented by Opus 4.8 directly; operator-gated. Bounded surface:
the `generate_policy` `fsp_rate` default + the two version files + this history file + one README line.

## The bug (grounded 2026-06-14, friendly-adversary round 2)

The generated FSP policy used `fsp_rate=(50/hr, 500/day)` for EVERY FSP role. But the per-round /
per-block roles vastly exceed that:
  - FTSO/FDC voting rounds are ~90s → ~40/hr, ~960/day **per subprotocol** for a per-round action.
  - PROTOCOL_PAYLOAD shares ONE rate bucket across FTSO+FDC (the bucket key is
    `(caller, wallet, message_type)`, not protocol_id) → ~80/hr, ~1920/day combined.
  - FAST_UPDATE / fastupdate-submit are per-block (~2000/hr ceiling).

So `(50, 500)` would **self-deny healthy operation within hours** — a sustained miss = a
minimal-conditions breach. The cap was set without deriving it from the duty cycle.

## The fix + the framing

The FSP rate is a **runaway-caller safety ceiling, not a duty-cycle target.** It must exceed the
HIGHEST legitimate FSP cadence or it self-denies. Raised the `generate_policy` `fsp_rate` default to
**`(5000/hr, 120000/day)`** — comfortably above per-block fast-updates (~2000/hr) with retry headroom.

Crucially (per the a104 finding-#11 framing): rate is **not** the primary blast control for these
value=0 consensus keys — message-type scoping + the value=0 cap + the hash-chained audit log are. A
looser ceiling for the naturally-rare per-epoch types (SIGNING_POLICY, VOTER_REGISTRATION, UPTIME,
REWARD_DISTRIBUTION) is therefore an acceptable trade for never self-denying the hot path.

## Documented follow-up (canary-informed, not in this ship)

Tighter, per-message-type rate tiers (epoch vs round vs block) and a **protocol_id-scoped FSP rate
bucket** (so FTSO and FDC PROTOCOL_PAYLOAD get independent budgets) are the rigorous next step — but the
exact caps are best validated by the 24h Songbird canary running through the daily-rate regime, so they
are deferred to it rather than guessed now.
