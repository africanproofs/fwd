## What changed (doctrine only — no code/test change)

- **Core #3** — endpoint rename `/v1/sign-and-send`→`/v1/sign-transaction` + a
  clarifier that fwd signs the decoded intent and never broadcasts (the model is
  *strengthened* by removing the broadcast surface).
- **Core #4** — fwd is the single nonce *reservation* authority (local SQLite only);
  no chain seed/reconcile from fwd (it has no egress) — seed via admin `nonce-init`
  (a8), reconcile via admin bounded `nonce-sync` (a13); release/keep/confirm driven
  by client report-back.
- **Core #11** — replacement is **client-triggered** (`sign-replacement`, a13); no
  receipt-watcher; reclaim = same-intent replacement + operator alarm, never
  cross-intent reissue.
- **Core #14** — fwd's code no longer touches RPC, so the validation boundary is the
  **client↔fwd↔chain integration**; the a12 funded Coston2 drill is the canonical
  instance. "Mocks lie" unchanged; only the locus of the live test shifted.
- **"What FWD IS NOT"** — added "**Not a broadcaster**"; "No public network exposure"
  → "**No network egress at all**" (code-level + `internal: true` network-level,
  verified).
- **`docs/threat-model.md` A4** — the network-exfil channel is **eliminated** (no
  egress); the pre-removal analysis retained as honest history (#18).
- **`docs/decisions.md` D20** — the formal decision record (the operator decision,
  the reclaim-mechanic decision made on the operator's behalf, rejected
  alternatives, the new orphaned-reservation risk).
