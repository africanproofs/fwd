## Reviewer corrections applied at commit

Three corrections, per the v0.4.0a5 precedent (Reviewer corrects logic
at commit when the canonical-prompt spec drifted, documents it):

1. **`policy_loader.py` check 1 — Reviewer-owned logic fix.** The
   submitted loader keyed `policy.callers` by `caller.policy_path`
   (`if caller.policy_path not in policy.callers; binding =
   policy.callers[caller.policy_path]`). The evaluator
   (`policy_engine.py` step 1) correctly keys it by `caller.name` and
   checks drift. In production `policy_path` is a path
   (`perm/main`) while `name` is a short id (`ftso-claimer`), so the
   loader would have false-positived and made D14 startup fail-fast
   reject every valid policy where `name != policy_path` (the normal
   case). **Root cause: the Reviewer's own canonical-prompt §2 check-1
   wording** speced the loader policy_path-keyed while speccing the
   evaluator name-keyed — a spec self-contradiction. Fixed the loader
   to mirror the evaluator: name-keyed lookup, drift check
   (`caller.policy_path != binding.policy_path`), then
   binding-resolves-to-permissions. This is the Core-invariant-#18
   "loader and evaluator MUST agree on the key space" alignment.
2. **`test_policy_loader.py` — fixed tests that encoded the buggy
   model.** Every check-1 test set `caller.name == caller.policy_path`,
   which masked the keying bug. `test_check_consistency_clean_returns_empty`
   now uses the realistic `_make_caller("my-caller", "perm/main")`
   shape (name ≠ policy_path), and a new
   `test_check_consistency_caller_policy_path_drifts_from_binding`
   regression test mirrors the engine's
   `test_step1_caller_policy_path_drift`.
3. **`policy_engine.py` `AllowDecision.decoded` — path-c type
   precision.** Submitted as `decoded: object  # ... to avoid circular
   import`. The circular-import justification was false:
   `fwd.domain.intent` is already runtime-imported at line 20 and
   imports zero `fwd.*` (stdlib + eth_abi + eth_utils only) — no cycle.
   Restored to the speced `decoded: DecodedIntent` with a proper
   runtime import. Non-behavioral.
