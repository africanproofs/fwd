# v1.1.0a77 — derived adversarial test coverage for the additive policy merge

**Type:** test-only (7 new `tests/unit/test_merge_*.py` files). No source change.
**Date:** 2026-06-04.

## Why

a76 made onboarding additive (adding a network must never remove an existing one) — a custody-critical invariant. Operator directive: derive + run automated tests. A multi-agent workflow fanned out one agent per adversarial dimension; each derived pytest, ran it, and classified any failure as real-bug vs bad-test.

## What was added

**241 tests across 7 files**, all passing:
- `test_merge_multinet.py` (12) — 2/3-network composition, claim-only/fsp-only/both mixes, per-network vs shared sender, add-order independence; superset assertion + daemon round-trip per case.
- `test_merge_preserve.py` (12) — existing keys byte-identical after an add; **hand-added keys the generator never emits survive** (operator caller/wallet/extra-contract/unknown top-level section, via `copy.deepcopy`); per-network `_recipient` predicates stay independent.
- `test_merge_adversarial.py` (23) — malformed `merge_into`: invalid YAML / list / scalar / empty / whitespace / comment-only / null sections / bad `fsp_self_submit` shapes; asserts `PolicyInitError` where raised and graceful fallback elsewhere.
- `test_merge_roundtrip.py` (122) — full network × capability × sender-mode matrix merged into the inert default and pairwise/incrementally, each passing `load_policy` + `check_consistency` (empty DB + real ABIs) with zero errors; incremental == one-shot.
- `test_merge_idempotent.py` (17) — re-merge no-op, order independence, 5× fixed-point, `fsp_self_submit` no duplicate growth.
- `test_merge_cli.py` (15) — `clifwd policy init --merge` reads `FWD_POLICY_PATH`, missing→fresh, inert==fresh, plain `init` unchanged.
- `test_merge_invariant.py` (40) — the superset property fuzzed: `set(merged[section]) ⊇ set(existing[section])` for every section + `fsp_self_submit` subset, incl. re-adding an already-present network.

## Outcome

**Zero real bugs** — the merge code held against every dimension. One agent self-corrected a bad test (a fabricated invalid base the schema rightly rejects) into a valid-base version. Full suite **775 passed / 1 skipped, 0 failed** (up from 535; +241), ruff clean, no source or pre-existing test touched (independently verified via `git status`). Verifies a76's invariant under adversarial load (Core #14 / #19 — the defect class "adding a network drops another" is now guarded by a fuzz, not just the happy path).
