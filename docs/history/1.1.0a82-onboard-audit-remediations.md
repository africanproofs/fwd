# v1.1.0a82 — onboard audit remediations (8) + policy_init merge guards

**Type:** `install/onboard` robustness remediations + two `policy_init` merge guards. No daemon change.
**Date:** 2026-06-06.

## Why

An audit of the onboarding wizard found paths where a failure was silent or mis-reported: fwd-unreachable looked like "wallet not present"; a deferred/skipped/failed key import still let the summary say "complete"; backup/write/chmod/mv failures were unchecked; a stale `.env` caller token was used without noticing it had been revoked; and there was no post-provisioning consistency gate. Two `_merge_policies` paths could also throw on a malformed (non-dict / non-list) section instead of degrading safely.

## What changed (`install/onboard`)

1. **Step 1 health** — parse `sealed_master` from the health JSON; `die` with a RESTORE-RUNBOOK pointer if it is not `ok` (master.key may have been regenerated).
2. **`wallet_addr` / `wallet_exists`** — distinguish *fwd-unreachable* from *not-present*: `wallet_addr` prints `<fwd-unreachable>`; `wallet_exists` warns and returns false rather than silently reporting "not present".
3. **`import_pasted`** — set `ONBOARD_INCOMPLETE=1` on every deferred / skipped / gave-up path, so the final summary cannot say "complete" when a key is missing.
4. **Policy backup + write** — `cp … || die` and `cat … > policy || die` (disk-space/permission failures no longer pass silently).
5. **`caller_ensure` CM-02 check** — when a `.env` token is preserved, warn if its 12-char prefix is **not** found in `clifwd callers list` (the token may have been revoked; hints `--rotate-missing-callers`).
6. **`env_write`** — `chmod … || die` and `mv … || die`.
7. **Post-provisioning consistency gate** — run `clifwd policy validate`; on inconsistency, warn + print the exact restore command for the just-made backup.
8. **INCOMPLETE banner** — rewritten to separate nonce-drift from incomplete-import and to print the precise idempotent re-run command.

## What changed (`app/policy_init.py`)

- **H1:** `_merge_policies` skips an additions section that is not a dict (`not add or not isinstance(add, dict)`), instead of merging a malformed value.
- **H2:** `fsp_self_submit` accumulation guards that the existing value is a list before iterating.

## Verification

`sh -n` + `dash -n` clean. Onboarding re-run against the live host exercised the new gates (health sealed_master parse, policy validate gate, INCOMPLETE banner on a deferred import). policy_init H1/H2 covered by the merge unit tests.
