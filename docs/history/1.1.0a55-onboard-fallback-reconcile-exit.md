# v1.1.0a55 — manual nonce fallback reconciles (not skips), onboard exits non-zero on unresolved drift, prints the exact clif rehearsal commands

**Type:** review-fix ship (`install/onboard` only). Reviewer (Opus) prescribed; Sonnet implemented in an isolated subagent; Reviewer binding-passed (full-diff read + tail-byte-identity check + `sh -n`/`dash -n`). Triggered by a SECOND independent adversarial review (of a54).
**Date:** 2026-06-02.

## Why

The second-round adversarial review verified all a54 fixes closed, then found two correctness bugs and one UX gap in the a52/a53 onboard wizard:

1. **The clif-down nonce fallback silently ignored an existing fwd row.** When `clif chain nonce` failed, `reconcile_nonce` called `nonce_seed "$(ask_nonce …)"` — but `nonce_seed` runs `clifwd nonce init`, which treats an existing (wallet, chain) row as "already initialized → skip". So on a rerun / import cutover with a stale fwd nonce AND clif temporarily unavailable, the operator's manually-entered value was discarded, the drift flag never fired, and onboard finished green on a wrong nonce — the exact mis-seed class the redesign exists to remove, hiding in the fallback.
2. **Unresolved fwd-ahead nonce drift still exited 0.** a54 made onboard PRINT "⚠ … NOT a completed onboard", but the script didn't exit non-zero, so `install.sh --onboard-rewards` / `fwd onboard` (which detect failure by exit code) reported success.
3. **UX:** onboard wrote `.env.<net>` but never told the operator the command that uses it. The correct rehearsal is the `clif` host wrapper (`clif --network <net> …`, which selects `.env.<net>`), NOT raw `docker compose run --rm clif …` (that reads the placeholder `.env`).

## What changed (all in `install/onboard`)

- **The manual fallback now reconciles.** `reconcile_nonce` is restructured so the clif-down branch sets `_rn_target` from `ask_nonce` (integer-validated: `case ''|*[!0-9]*) die`) and **falls through to the SAME `fwd_nonce_get` reconciliation tail** (absent→`init`; equal→in-sync; behind→`sync`/`init --force`; ahead→drift-flag) as the chain-truth path. The manual value is now honored against an existing row, and the drift flag fires in fallback mode too. The reconciliation tail is byte-identical to before. (`nonce_seed`/`seed_sender` are now unused — left in place; a future cleanup may remove them.)
- **`exit 1` on unresolved drift.** The `ONBOARD_INCOMPLETE` final branch now exits non-zero after the warning, so the caller (install.sh / the `fwd onboard` wrapper) sees the failure.
- **Onboard prints the exact rehearsal commands.** The final output now prints, per onboarded network, `clif --network <net> claim --type fee` and `clif --network <net> fsp uptime/rewards --epoch <N>`, with an explicit note to use the `clif` wrapper (not raw `docker compose run`, which reads the placeholder `.env`).
