# v1.1.0a83 — codebase cleanup (ruff format, archaeology-comment removal, planning docs quarantined)

**Type:** non-behavioural cleanup. No logic change, no API change.
**Date:** 2026-06-06.

## Why

After ~80 ships the source had accumulated formatting drift and stale comments — references to retired designs (Vault, `/sign-and-send`, in-daemon RPC) and version-by-version archaeology that Core invariant #18 forbids in current-state code. Two planning docs sat in `docs/` (current-state space) when they belong in the quarantined history tree.

## What changed (two content commits + the version bump)

- **`ruff format` + `ruff check --fix`** across the source and test tree — line reflow, import sorting, trivial lint fixes. Pure formatting/idiom; no behaviour touched (the large insertion/deletion count is reflow, not logic).
- **Stale-comment / archaeology removal** across ~26 modules — dropped `was X` / `retired in vX` / `used to` / discarded-design references (Vault, sign-and-send, RPC-era retry) from current-state source, per Core #18 (history lives only in `docs/history/` + `decisions.md`).
- **Planning docs quarantined** — `docs/implementation-plan.md` and `docs/zero-egress-architecture-plan.md` moved to `docs/history/` (they describe how the code got here, not what it is).

The companion consumer `clif` had its own parallel cleanup ship (clif v0.5.15) in its own repo; this record covers fwd only.

## Verification

Full unit suite green after the sweep (no behavioural delta — formatting + comments + file moves only). `ruff format --check` and `ruff check` clean.
