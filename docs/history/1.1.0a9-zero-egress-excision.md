# v1.1.0a9 — zero-egress excision / sign-only

**Shipped 2026-05-27.** The core of the zero-egress initiative
(`docs/zero-egress-architecture-plan.md`). fwd stops being sign-**and-send** and
becomes a **sign-only** signer: it signs an EIP-1559 transaction and returns the
signed raw bytes + a locally-computed tx hash; the **client** broadcasts. fwd now
makes **no network call** — the entire JSON-RPC egress surface is gone.

## What shipped

**Deleted (the egress surface):** `src/fwd/infra/rpc.py`,
`src/fwd/app/receipt_watcher.py`, `src/fwd/app/nonce_reconcile.py`,
`src/fwd/app/wallet_balances.py` (+ their four unit-test files). `ALLOWED_CHAINS`
/ `CHAIN_LABELS` went with `rpc.py` — policy is the sole authZ; there is no
RPC-routing rail.

**`sign_and_send.py` → `sign_transaction.py`:** the `rpc` parameter and all five
RPC call sites (chain-id verify, on-chain nonce seed, `fee_history`,
`estimate_gas`, broadcast) are removed. The request now carries client-supplied
`gas` + `max_fee_per_gas` + `max_priority_fee_per_gas`; the result carries
`signed_raw_tx` (for the client to broadcast) + a locally-computed `hash`
(`"0x"+signed.hash.hex()`). The tx row persists `status="pending"`,
`submitted_at=None` (the client has not broadcast). The forensic commit-before-raise
discipline (Core invariant #5/#19) is preserved on every failure arm:
cap-rejection, policy-deny, nonce-not-initialized, and pre-sign failure.

**New guards:** client-supplied gas/fees are bounded by `FWD_MAX_GAS` /
`FWD_MAX_FEE_PER_GAS` settings (+ the EIP-1559 `maxPriorityFeePerGas <=
maxFeePerGas` rule) → `TxParamsRejected` (400), checked before the policy gate so a
cap reject touches no rate bucket. An uninitialized `(wallet, chain)` is now a
terminal `NonceNotInitialized` (409, "call `POST /v1/admin/nonce-init`") — there is
no on-chain seed fallback (that is the v1.1.0a8 nonce-init command's job).

**Surface:** `/v1/sign-and-send` retired; `POST /v1/sign-transaction` mounted.
`/healthz` drops its `rpc` field. `RpcManager` wiring removed from
`app/dependencies.py` (`RequestScope` no longer carries an RPC handle).
`main.py::lifespan` loses the receipt-watcher task and the startup nonce-reconcile
(keeps `mlockall` + policy load). `settings.py` drops the three `RPC_URL_*` + the
five `fwd_watcher_*` fields and adds the two caps. `.env.example` cleaned.
`/v1/sign-fsp-message` and `nonce-init` are untouched.
