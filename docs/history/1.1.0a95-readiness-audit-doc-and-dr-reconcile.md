**Date:** 2026-06-09.

## Why

A CTO-grade deployment-readiness audit (fwd / fwd-client / clif; 27 agents, 100 findings,
17 high/critical adversarially confirmed) surfaced several fwd items that are
documentation/operations gaps, not code defects:

- **tech-debt-03** — `FSP_AUTO_ENABLED` doc-drift: a94 made `fwd onboard` write the flag `=true`
  by default, but README / `production-setup` / `one-command-install` still said the operator
  must set it ("hard-off by default").
- **tech-debt-02** — a94 shipped without its history file + index line (3-artifact discipline).
- **ops-03** — the restore runbook documented RESTORE but had no BACKUP procedure (how to create
  the off-host bundle it depends on) and no schedule guidance; the operator's documented bundle
  predated the current 3-wallet prod state.
- **fwd-02 / custody-security** — the claim-executor `setClaimExecutors` DR mechanic (Core #17
  `[Flag — DR mechanic unverified]`) and the master-key-lost restore were documented but had no
  drill procedure.

## What changed

- **Doc-drift reconciled** (tech-debt-03): README + `docs/production-setup.md` +
  `docs/one-command-install.md` now state `fwd onboard` writes `FSP_AUTO_ENABLED=true` by default
  and that the `clifctl up <net>` bring-up — not the flag — is the gate; `=false` keeps a network
  idle.
- **`docs/restore-runbook.md` gained `## 0. Backup`**: a consistent SQLite snapshot
  (`sqlite3 .backup`, never `cp` a live WAL'd db), bundling the four custody inputs + clif envs,
  age/gpg encryption (fail-closed — never write `master.key` off-host in the clear), shred the
  staging dir, copy off-host + verify decrypt, a cron example, and the "take a fresh bundle after
  EVERY custody change" rule.
- **`docs/restore-runbook.md` gained `## Disaster-recovery drills (Coston2)`**: (A) the
  `ClaimSetupManager.setClaimExecutors` executor re-auth drill (regen → re-auth → preflight →
  claim) with acceptance criteria + the note to lift the Core #17 `[Flag]` once it passes; (B) the
  master-key-lost full-restore drill on a throwaway host.
- **Retroactive `docs/history/1.1.0a94-onboard-fsp-auto-default.md`** + this index line
  (tech-debt-02).
