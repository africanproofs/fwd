## What changed

- **install.sh `--with-clif`: seed a placeholder clif `.env`.** The clif overlay
  service defs (`docker-compose.clif.yml`) reference `env_file:
  ${CLIF_ENV:-.../clif/.env}`. compose validates that env_file for ALL service
  defs in the merged file — even the clif daemons that install.sh leaves stopped
  — so `up -d fwd litestream` aborts `env file not found` when the cloned clif
  has no `.env` (gitignored). Fix: after cloning clif, `cp .env.example .env`
  if absent — a placeholder so the merged compose parses; the operator fills in
  real values (NETWORK, fwd caller tokens, wallet names) during onboarding,
  before starting the clif daemons.
