# v1.1.0a39 — operator CLI: standardize the docs on the `clifwd` host wrapper

**Type:** docs ship (no daemon code change).
**Date:** 2026-05-31.
**Authoring:** Reviewer (Opus); operator-gated.

## Why

The README quickstart documented admin ops as
`docker exec fwd clifwd wallets create --name … --policy …` — too verbose for
routine use. `fwd` already ships the `clifwd` host wrapper (`install/clifwd` →
`docker exec "${FWD_CONTAINER:-fwd}" clifwd "$@"`); the operator just wasn't on a
host with it on `PATH`, and the docs led with the long form. The operator chose
to **reuse `clifwd`** (rather than add a new `fwc`/`fwdctl` command). So this ship
puts the wrapper on `PATH` and leads the operator-facing docs with `clifwd …`.

## What changed

- **Docs lead with `clifwd …`** (current-state only; append-only record
  untouched): `README.md` quickstart steps 3–6 (`clifwd health` / `wallets
  create` / `callers create` / `nonce init`) + the `## CLI` section + the
  no-host-port note now use `clifwd …`, with one explanatory line — "`clifwd` is a
  host wrapper for `docker exec "${FWD_CONTAINER:-fwd}" clifwd`; if it isn't on
  your `PATH`, prefix with `docker exec fwd`." `CLAUDE.md` (§Scope + no-host-port
  bullet) and `docs/architecture.md` (network table + the caller-key example)
  now name the wrapper. `docs/one-command-install.md` already used `clifwd …`.

## Host action (not a repo change)
The `clifwd` wrapper was installed on the production host at
`~/.local/bin/clifwd` (on `PATH`, no sudo). Verified: `clifwd health` →
`{"master":"ok","fwd":"ok"}` and `clifwd wallets list` run from the host with no
`docker exec` prefix (resolving to the live `fwd` container). On install.sh-
deployed provider hosts the wrapper is installed to `/usr/local/bin`
automatically. (The `fwd` lifecycle wrapper defaults to `/opt/fwd` and is for
install.sh-deployed hosts; it was not installed on this manually-deployed host.)

## Not in scope
Singular sub-command aliases (`clifwd wallet`/`caller`) were considered and left
out — `clifwd wallets create` works today, whereas an alias would only take
effect after a container rebuild+redeploy.

## Files
`README.md`, `CLAUDE.md`, `docs/architecture.md`, version files.

## Verification

- README quickstart/CLI examples use `clifwd …` (the only `docker exec fwd clifwd`
  left is the deliberate fallback note).
- version-consistency green; no `src/` change.
