# v1.1.0a16 — README brought current to the zero-egress surface

**Ship type:** documentation reconciliation (Core invariant #18 — doctrine must not
silently drift from code). No code, no endpoint, no behaviour change.

## Why

The operator reviewed the public repo (github.com/africanproofs/fwd) and found the
root `README.md` frozen at **v0.3.0-alpha** while the code had shipped to v1.1.0a15.
Every load-bearing sentence had drifted, and there were no real usage instructions —
exactly the failure Core #18 exists to prevent, on the most-read public artifact.

  no-host-port / dual-homed-caller model.

  up` → `docker exec fwd clifwd wallets/callers/nonce …` → the client signing loop.

  `gitlab.com/proofs.africa/fwd-client` (public) as the canonical way to interface to
  fwd; clif already depends on it.
