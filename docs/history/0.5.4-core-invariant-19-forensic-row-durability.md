## Why this ship

The v0.5.2 fix (drill-surfaced D16/Core-#5: denied/error audit rows
rolled back when the exception unwound `session_scope`) closed the
*instance*. It did not close the *class*. The same defect had already
shipped once — v0.5.0a6 in `main.py` (audit row discarded on
`SystemExit` before commit), point-fixed during the a7 Reviewer pass —
and **recurred** at v0.5.2 in `sign_and_send.py`'s three exception
arms because the a6 fix was an instance-patch with no codified
invariant and no class-level test on real infrastructure. The
recurrence (three ships and ~a week apart, caught only by the Phase 7
GA live drill) is the proof that a point-patch without doctrine + a
class-test is a deferral of the next instance. v0.5.4 codifies the
class so the next exception path that writes a forensic row is checked
against doctrine, and the next instance fails a test rather than a
production migration.

## What was codified

- **`CLAUDE.md` — new Core invariant #19, "Forensic audit rows survive
  the failure they record."** The structural rule (forensic row for a
  denied/errored/aborted op committed independently of the txn the
  failure rolls back); the forbidden anti-pattern (append on shared
  session → `raise` → `session_scope` rollback discards it); the `fwd`
  mechanism (commit-before-raise on the **single** shared session —
  never a second `session_scope`, which re-introduces the v0.4.5
  two-session BEGIN IMMEDIATE deadlock); the operational-correctness
  nuance (deny keeps the D14 rate increment; pre-broadcast nets zero;
  broadcast-fail keeps the reserved nonce); the mandatory
  real-`session_scope` regression test with a self-validating
  without-commit control; the v0.5.0a6→v0.5.2 history; and the deeper
  rule — *a defect found is a defect class; closed only when named in
  doctrine AND guarded by a class-test on real infra*.
- **`CLAUDE.md` — Core invariant #14 augmented**: the v0.4.5
  concurrency bug and the v0.5.2 deny-audit bug named as the two
  canonical "mocks lie / the live drill earned its keep" proofs, with
  the meta-rule cross-referenced to #19.
- **`decisions.md` D16** — a "Forensic-row durability" bullet (the
  rule, the fwd mechanism, the single-session constraint, the
  mandatory test, the recurrence history).
- **`architecture.md` § Audit log** — mirror.
- **`threat-model.md`** — the "abuse becomes immediately visible"
  mitigation made honest: true for denied/errored requests (the
  policy-probing detection case) only since v0.5.4/#19; pre-fix an
  attacker probing the policy left no audit trace.
