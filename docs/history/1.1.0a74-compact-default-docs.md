# v1.1.0a74 — compact is the documented onboarding default (drop `--guided` from the runbook commands)

**Type:** docs-only (`docs/production-setup.md`). No code change.
**Date:** 2026-06-04.

## Why

The operator found the onboarding output unchanged-feeling between ships because every command they copied carried `--guided` — the deliberately verbose mode. Compact (the lean cockpit: step titles + `·` action notes + summary + unconditional safety/CUTOVER blocks, no explanation paragraphs) is *already* the coded default (`install/onboard:49`, `install.sh:55` → `${FWD_OUTPUT:-compact}`); the only thing forcing guided was the documented commands (and the hand-offs that copied them). Making compact the default *experience* is therefore a docs change, not a code change — nothing about the default behaviour flips.

## What changed (`docs/production-setup.md` only)

- Dropped `--guided` from the three copy-paste commands: the `curl|sh` install, the `git clone` install, and the `fwd onboard rewards` command. They now yield the compact cockpit by default.
- Reworded the install note to state the default explicitly and point at the opt-in: "Output is a compact operator cockpit by default; add `--guided` (or `FWD_OUTPUT=guided`) for the verbose, first-timer walk-through."
- Added one line under the onboard command: "Add `--guided` for the step-by-step walk-through; the default compact output still prints every safety gate and on-chain action."

`README.md` and `docs/one-command-install.md` already described `--guided` correctly as opt-in (no command carried it) — unchanged. No `install/*` change: the scripts already default to compact and only propagate `--guided` when the operator passes it.

## Out of scope

The compact output's content/structure is unchanged — collapsing the per-function sections or a one-screen summary were separate options the operator did not pick. The a72 review already confirmed compact prints every safety gate unconditionally.

## Verification

`grep -n -- --guided docs/production-setup.md` → only the two opt-in notes remain; no command carries it. A fresh `fwd onboard rewards … --import-existing` (no flag) renders the compact cockpit with explanation paragraphs suppressed and all safety/on-chain blocks intact.
