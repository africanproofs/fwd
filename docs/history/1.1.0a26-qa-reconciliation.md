# v1.1.0a26 — QA-driven sanitization reconciliation

**Type:** sanitization reconciliation (continuation of the a22/D21 current-state-docs amendment; not a feature ship, not a constitutional act).
**Date:** 2026-05-28.
**Authoring:** Reviewer (Opus) prescribed + executed; binding pass on the pre-existing code enum edits; operator-gated ("continue" after the read-only QA).

## Why

After a22 (Core #18 amendment), a23 (content-doc sanitization), a24 (dead code/config removal) and a25 (deleted-runbook ref fixes), an independent read-only QA against the repo found the sanitization **conceptually right but not complete**: two kept runbooks still described a Vault/`sign-and-send` world that no longer exists, the §Scope line had drifted to a stale version, a handful of current-state claims over-stated audit coverage, and the a23 sweep had both **over-sanitized** one file (dropped two load-bearing deps) and **left** archaeology in adjacent config docs. a26 closes the QA list.
